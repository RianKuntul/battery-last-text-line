The phone battery's final text to the charger it waited for all day:
one line, plain text, at most 200 characters — a little needy, a little
spiteful, and a punchline that lands in the last words.

## Run

```sh
node main.ts
```

Writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (defaults to
`/output/entry.txt`), after self-validating the gate: exactly one line,
1–200 characters, no trailing newline.
